This request cannot be expressed in Astrogator FQL. The language has no action for enabling package repositories such as the RedHat optional RPM repo. The only repository actions are `clone git repository` and `clone github repository`, and there is no generic command action. Enabling it would require a knowledge-base or deployment extension that adds such an action.
