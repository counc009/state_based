This request can't be expressed in Astrogator FQL with the pinned KB:

- **nginx is not in the knowledge-base catalog.** The supported services are ssh server, postfix, and apache server, and nginx is not a supported package either.
- **FQL has no "enable on boot" action.** Only `start SERVICE service` and `stop SERVICE service` exist.

If Apache would work instead, the closest valid query is:

`if os is Debian based then install apache server; start apache server service otherwise install apache server; start apache server service`
