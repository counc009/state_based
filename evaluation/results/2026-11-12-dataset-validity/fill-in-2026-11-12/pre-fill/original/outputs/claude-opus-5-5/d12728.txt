**This request can't be expressed in Astrogator FQL.** `install` only accepts packages from the pinned knowledge-base catalog: bash, zsh, postfix, apache/apache server, ssh client, ssh server, and numpy. Pip isn't one of them, and writing `install pip` would produce a query the KB can't resolve.

The closest supported options use pip internally:

- `create virtual environment in "/PATH/venv". install numpy in virtual environment at "/PATH/venv"` (pip numpy inside that environment)
- `if os is Ubuntu then install numpy` (Ubuntu also permits pip numpy)

If pip needs to be installed directly, the KB would need a catalog entry for it, such as apt/dnf `python3-pip`.
