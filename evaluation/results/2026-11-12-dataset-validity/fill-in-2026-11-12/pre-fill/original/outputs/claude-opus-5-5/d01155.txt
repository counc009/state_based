This request can't be expressed as a valid query, because Vagrant is not in the pinned knowledge-base package catalog. `install` only accepts these catalog descriptions: bash, zsh, postfix, apache/apache server, ssh client, ssh server, and numpy.

If Vagrant were added to the knowledge base, the query would be:

install vagrant

Omitting `version=` installs the default (latest) version.
