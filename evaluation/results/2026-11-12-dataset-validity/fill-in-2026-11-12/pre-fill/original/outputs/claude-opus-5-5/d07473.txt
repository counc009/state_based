This request can't be expressed exactly. Astrogator FQL has no link or symlink action, and the source path of the tcollector start/stop script isn't known.

The closest supported approximation **copies** the script instead of linking it, with the unknown source left as an unspecified value:

```
copy file from ?path to "/etc/init.d"
```

A copy won't pick up later changes to the original script, so this is a substitute, not a true link.
