This request can't be expressed in Astrogator FQL. The language has no action for adding a package repository or PPA, so I won't invent one such as `add ppa repository ...`.

A workaround that writes an APT sources file with `write ... to "/etc/apt/sources.list.d/..."` would not be faithful either. It needs the Ubuntu release codename, which a quoted literal can't leave unspecified. It also can't import the PPA's signing key, so the result would be an incomplete or broken repository setup.
