This request cannot be expressed in FQL with the pinned knowledge base:

- **No `enable` action for services.** Only `start SERVICE service` and `stop SERVICE service` exist, and starting a service is not the same as enabling it at boot.
- **`ntopng_service` is not in the service catalog.** The only supported services are ssh server, postfix, and apache server.

If you meant to start it now and ntopng is added to the knowledge base, the query would be:

start ntopng service
