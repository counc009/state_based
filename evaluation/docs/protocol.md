# Frozen comparison protocol

Use the supplied PLDI draft and recovered research inputs as the baseline authority. The draft's section 6.2 is a TODO; it does not specify a final NL-to-FQL prompt. Accordingly `compact-v1` is explicitly the recovered September research baseline, not an invented paper prompt. Preserve the original playbook-generation prompt and pipeline independently; its Appendix B is referenced in separate supplemental materials absent from the supplied 32-page PDF. Obtain that supplement before refreshing playbook generation.

The new experiment is factorial: every selected model receives both compact-v1 and handbook-v2 on exactly the same targets and demonstrations, five independent requests per cell. The earlier handbook-v1 remains available with `--variants compact-v1 handbook-v1 handbook-v2` for an additional ablation; that increases costs by 50%. Never pool variants or historical three-/ten-repeat results. No semantic-scoring outcomes were used to author v2, which adds a generic silent requirements/scope/literal check. The source handbook was designed previously from parser, semantic analyzer and KB sources; it exposes benchmark-related domain engineering. V2 is a hypothesis, not an established improvement. Prompt length and content change together.

Freeze complete input messages, source/dataset/prompt/config/runner hashes, exact request model IDs, maximum billable output and reasoning effort. OpenAI is requested at high effort without temperature/top-p/seed; this preserves the recovered baseline's sampling choice. Direct API transport replaces the old isolated agent-CLI transport, which had an extra wrapper instruction and provider defaults. Report that as a transport change, not an exact replay of historical outputs. Provider aliases may change; retain returned model IDs, response IDs and timestamps. The run ledger timestamps every attempted cell and records the immutable manifest hash with each response. Five repetitions have independent sessions, not guaranteed statistical independence.

Budget before inference: count all prompts × variants × models × five. The full recovered suite and six-model slate require 1,260 completions (840 API and 420 local). At the current 4,096-token output cap the conservative byte-based input envelope gives $172.87965 for API calls; local hardware/storage costs are excluded. This includes the configured 5-minute cache-write overhead and is a planning envelope under documented standard token rates, not a provider-enforced dollar cap or account invoice. It includes no batch/cache discounts or retry allowance. One-hour cache writes, long-context or changed rates require repricing. The older $158.94756 base-input-only proposal is retained historically and is superseded for approval. Model and token allowances must be verified for the actual endpoint. `--budget-usd` reserves the full envelope before each attempt and `--max-calls` is a second guard. No automatic retries occur. Stop for failures rather than altering prompts or buying more tokens to improve an answer.

Keep failed, incomplete, refused and missing cells in denominators. The analyzer reports all planned cells and compiler return codes, retains raw text (including code fences), and performs no repair. Compiler success measures supported formal-language processing only. Need independent blinded adequacy/intent judgments, including omissions and extra requirements, and end-to-end verifier decision comparisons before asserting scientific benefit. Do not use exact text equality as a correctness oracle. Summarize paired per-task/model/variant fractions, five-repeat outcome distributions and prompt-cluster uncertainty when the full suite is complete. Broader human readability/user-validation claims require a separate user study.

Do not tune on held-out outcomes. Freeze the source-only prompt before generation; any change after reading predictions is a new exploratory version and must use a new evaluation split. Historical demonstrations and KB overlap are declared. Existing benchmark references, postprocessing and execution labels remain untouched. Do not execute generated playbooks on a personal VPS or this workspace; full code evaluation requires the draft's resettable Debian 12.14, Ubuntu 24.04.4 LTS and RHEL 9.8 environment and authoritative tests.
